# 国际化（i18n）

Aether 的国际化系统通过 locale 文件管理多语言文本，在 AE 模板中以 `@i18n.xxx.yyy` 语法引用，运行时支持动态切换语言。

## locale 文件结构

每个语言对应一个 TOML 文件，放置在 `src/i18n/` 目录下。文件名即为语言代码。

### 文件命名

| 文件路径 | 语言代码 |
|---|---|
| `src/i18n/zh-CN.toml` | 简体中文 |
| `src/i18n/en.toml` | 英文 |
| `src/i18n/ja.toml` | 日文 |

### 文件格式

以 `zh-CN.toml` 为例：

```toml
[home]
title = "你好"
click_me = "点我"
counter = "计数: {count}"

[settings]
language = "语言"
theme = "主题"
about = "关于"
```

以 `en.toml` 为例：

```toml
[home]
title = "Hello"
click_me = "Click Me"
counter = "Count: {count}"

[settings]
language = "Language"
theme = "Theme"
about = "About"
```

### 插值变量

值中可以使用 `{变量名}` 语法定义插值变量：

```toml
counter = "计数: {count}"
welcome = "欢迎, {name}!"
```

## aether.toml 配置

在项目配置文件中设置默认语言和回退语言：

```toml
[i18n]
default = "zh-CN"
fallback = "en"
```

| 字段 | 说明 |
|---|---|
| `default` | 应用启动时的默认语言 |
| `fallback` | 当当前语言缺少某个 key 时，回退到此语言查找 |

## AE 模板中的引用

### 基本引用

使用 `@i18n.节名.键名` 语法：

```ae
Text(@i18n.home.title size=14)
```

生成 Swift：

```swift
Text(I18nManager.shared.tr("home.title"))
```

### 带插值的引用

```ae
Text(@i18n.home.counter size=14)
```

生成 Swift（逻辑层负责传入插值参数）：

```swift
Text(I18nManager.shared.tr("home.counter", args: ["count": "\(viewModel.logic.getCount())"]))
```

## 运行时语言切换

### 从 Rust 逻辑中切换

```rust
pub fn switch_to_english(&mut self) {
    sys_set_language("en".to_string());
}
```

### 切换流程

```
sys_set_language("en")
    ↓
I18nManager.shared.setLocale("en")
    ↓
所有 @i18n 引用自动更新
    ↓
UI 刷新显示英文
```

### 获取当前语言

```rust
let current = sys_get_language(); // "zh-CN" 或 "en" 等
```

## 回退机制

当查找一个翻译 key 时，系统按以下顺序查找：

1. **当前语言** — 如 `zh-CN.toml` 中的 `home.title`
2. **回退语言** — 如 `en.toml` 中的 `home.title`
3. **key 本身** — 如 `home.title`，作为最终兜底显示

### 示例

假设当前语言为 `ja.toml`，但 `ja.toml` 中缺少 `settings.about`：

```toml
# ja.toml
[settings]
language = "言語"
# 缺少 about
```

```toml
# en.toml（fallback）
[settings]
language = "Language"
about = "About"
```

此时 `@i18n.settings.about` 会回退到 `en.toml` 中的值，显示 "About"。

## 完整工作流

```
1. 编写 src/i18n/zh-CN.toml 和 src/i18n/en.toml
2. 在 aether.toml 中配置 default 和 fallback
3. AE 模板中使用 @i18n.xxx.yyy 引用文本
4. Rust 逻辑中通过 sys_set_language / sys_get_language 管理语言
5. 构建系统生成 I18nManager 代码，自动处理回退和运行时切换
```
